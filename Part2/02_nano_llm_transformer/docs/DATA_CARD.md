# Data Card

- **Name:** Lumen educational SFT seed corpus
- **Origin:** Authored examples included with this project
- **Format:** Plain UTF-8 text with explicit system/user/assistant delimiters
- **Purpose:** Pipeline validation and transformer education
- **Sensitive data:** None intended
- **License:** Project-authored content; review licenses before adding external text
- **Limitations:** Tiny, English-only, narrow subject coverage, synthetic conversational structure
- **Processing:** Whitespace normalization, exact-block deduplication, deterministic 90/10 split, UTF-8 byte encoding
- **Do not use for:** Claims of general knowledge, safety, fairness, or production readiness
